# Writing sample analysis

Analyze patterns only when samples are creator-owned and representative enough for the claim.

## Evidence checklist

- Openings: claim, scene, question, contrast, context setting.
- Sentence and paragraph rhythm: length, fragments, transitions, whitespace.
- Diction: concrete/abstract, technical/plain, formal/conversational.
- Reasoning: examples, causal explanation, concessions, objections, evidence.
- Stance: certainty, humility, vulnerability, humor, disagreement.
- Endings: synthesis, implication, question, instruction, invitation.
- Repeated anti-patterns visible through creator edits or explicit feedback.

For every proposed pattern, record sample/location, observation, possible alternative explanation, and confidence. One occurrence is an example, not a stable voice rule. Never infer demographic, personality, or private facts from prose.
