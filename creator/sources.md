# Source guidance

## Approved recurring sources

None supplied yet.

## Default source policy

- Prefer primary, dated, authoritative sources for factual claims.
- Preserve a link or precise citation and access/publication date where useful.
- Separate sourced fact, external disagreement, and interpretation.
- Treat source preferences as unknown until the creator approves them.

## Exclusions and confidentiality

No creator-specific exclusions are established. Never submit confidential material to an external search or service without explicit permission.
